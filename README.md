# SMART PRINT — للطباعة المتقدمة

تطبيق واجهة كامل (React 19 + Vite + Tailwind 4) لبرنامج **إدارة الطباعة المتقدمة والاسكانر الفوري** لطابعات HP PageWide، مع معالج تثبيت بأسلوب Windows 11، شاشات ترحيب، صفحة إعدادات بثيمات وخطوط، ولوجو مجسم.

---

## ✨ ما تم تنفيذه في هذا التحديث

### 1) الهيدر الرئيسي (غامق — جريدانت أزرق وكحلي)
- جريدانت متعدد الطبقات: كحلي غامق → أزرق ملكي مع لمسة سماوية (`--t-head-1..4`).
- **اسم البرنامج «SMART PRINT» الكلمتان جنب بعض وعلى أقصى الشمال**، وتحته «للطباعة المتقدمة».
- **أزرار الإغلاق والتكبير والتصغير على أقصى اليمين**.
- **الطابعة المتصلة تظهر بكلمة «متصل» وجنبها علامة صح فقط** (بدون اسم/IP).
- **زر تكبير وتصغير الواجهة** (80% – 130%) مع نسبة مئوية قابلة للنقر لإرجاع 100%.
- **أيقونة ترس ⚙ لفتح صفحة الإعدادات**.

### 2) الأزرار أسفل الهيدر
- الزرّان اللذان كانا في الهيدر نزلا أسفله تحت شريط التنقل: **«طباعة»** و**«الاسكانر»**.

### 3) الفوتر الغامق
- حالة النظام (متصل ✓، الدرج، فوهات PageWide، WIA، عدد الملفات).
- **«تصميم وتنفيذ م/ وائل الجمال» + 01222355769** (قابل للاتصال).
- **مستكشف الكود أصبح أيقونة `</>` فقط** في الفوتر بدلاً من زر نصي طويل.

### 4) هيدرات غامقة للأقسام
هيدر غامق موحّد (`SectionHeader`) لكل من: **إدارة الملفات** · **التحكم في الطباعة والأدراج** · **المعاينة البصرية** · **أزرار الاختصارات الذكية** · **خيارات الطباعة** — ونفس الأسلوب في تبويب الاسكانر والنوافذ المنبثقة.

### 5) الأنيميشن
- `btn-pop`: رفع خفيف + تكبير عند المرور + انضغاط عند النقر.
- `btn-shine`: لمعة تمر على الأزرار الرئيسية.
- `anim-gradient` (أزرار متدرجة متحركة)، `anim-float`، `anim-glow`، `fadeUp` متتالي للبطاقات، وحركة تدوير الترس.

### 6) صفحة الإعدادات (من أيقونة الترس)
| التبويب | المحتوى |
|---|---|
| **نوع الخط** | Tahoma (الافتراضي) · Cairo (كايرو) · Noto Kufi Arabic (نوتو كوفي) + معاينة حية |
| **المظهر** | 4 قوالب: أزرق وكحلي (الافتراضي) · كهرماني في برتقالي · سماوي مائي · أزرق بترولي + شريط تكبير الواجهة |
| **معلومات البرنامج** | الإصدار، التقنية، البروتوكولات، المزايا، أيقونة سطح المكتب |
| **الدعم والتواصل** | م/ وائل الجمال — 01222355769 (هاتف/واتساب/بريد/موقع) |

كل الإعدادات تُحفظ في `localStorage` وتُطبّق فوراً على كل الواجهة عبر متغيرات CSS (`data-theme` + `--app-font`).

### 6.5) اللوجو الرسمي PRO SALES (المرفق من المستخدم)
- `src/assets/pro-sales-logo.png` — خلفية سوداء أُزيلت تلقائياً (شفافية كاملة) + نسخة خفيفة `-sm` للهيدر.
- يظهر الآن في: **الهيدر الرئيسي** · **شاشة الترحيب (Splash)** · **شاشة ترحيب التثبيت** · **خيارات التثبيت** · **شاشة جاري التثبيت** · **معلومات البرنامج** · **أيقونة المتصفح (favicon)**.

### 7) اللوجو والأيقونة
- `Logo3D`: لوجو **مجسّم** مبني بـ CSS 3D (طبقات عمق + لمعة + توهج) يكتب «SMART PRINT» كلمتين جنب بعض.
- `DesktopIcon`: **أيقونة سطح المكتب** بعد التثبيت (بلاطة Windows 11 مجسّمة).
- `favicon` للمتصفح في `public/favicon.png`.

### 8) شاشات التثبيت والترحيب
1. **شاشة ترحيب عند الضغط على ملف التثبيت** (Welcome) بصورة ثلاثية الأبعاد + مزايا.
2. **خيارات التثبيت** (المسار، اختصارات سطح المكتب/قائمة ابدأ، التشغيل بعد التثبيت).
3. **شاشة التثبيت أثناء العملية** بأسلوب Windows 11: صور متغيرة + 6 خطوات تقدّم + شريط تقدم.
4. **شاشة اكتمال التثبيت** مع زر التشغيل.
5. **شاشة ترحيبية (Splash)** أثناء فتح البرنامج مع شريط تحميل وخطوات تهيئة.

> لإعادة مشاهدة معالج التثبيت: من DevTools → `localStorage.removeItem('smartprint.settings.v1')` ثم Refresh.

| # | الميزة | كيف تستخدمها |
|---|---|---|
| **2** | **علامة مائية + ترويسة + رقم صفحة** تُرسم على الورقة في المعاينة وتُطبع | الإعدادات ⚙ → تبويب «العلامة المائية» (نص، موضع مائل/وسط/أسفل، شفافية، حجم، لوجو، رقم صفحة) |

| **5** | **طابور طباعة (Spooler)** بتقدّم حي وترتيب | زر «الطابور» أسفل الهيدر أو `Ctrl+Q` — إيقاف مؤقت، استكمال، إلغاء، تحريك |
| **6** | **توقيع إلكتروني** بالرسم الحر + توقيعات جاهزة + ختم | زر «توقيع» أو `Ctrl+E` — يُرفق تلقائياً في الورقة |
| **8** | **إدارة المخزون والأحبار** مع تنبيهات النقص والخصم التلقائي | زر «المخزون» أو `Ctrl+K` |
| **9** | **تصدير/استيراد الثيم** كملف JSON بين الأجهزة | الإعدادات ⚙ → المظهر → «تصدير الثيم / استيراد ثيم» |
| **10** | **اختصارات لوحة المفاتيح** + لوحة مساعدة | `F1` لعرض اللوحة — `Ctrl+P/O/Q/K/E/،` ، `+/-`، `0`، `S`، `B`، `Esc` |

## 🆕 تحديث: الترخيص + 4 ميزات مستندات

### 🔐 نظام الترخيص (تجربة 15 يوم + تفعيل مدى الحياة)
| العنصر | التفاصيل |
|---|---|
| **الفترة التجريبية** | 15 يوماً من أول تشغيل — شريط تنبيه في كل الصفحات + تحذير بلون أغمق في آخر 3 أيام |
| **سيريال التفعيل** | `SPRD-XXXX-XXXX-XXXX-XXXX` موقّع HMAC‑SHA256 ومربوط ببصمة الجهاز |
| **مرة واحدة فقط** | السيريال يُعلَّم «مُستهلك» في السجل عند التفعيل؛ المحاولة الثانية تُرفض |
| **مكان الإدخال** | زر «تفعيل» أسفل الهيدر + شاشة قفل كاملة عند انتهاء التجربة |
| **رسالة نجاح عائمة** | بطاقة احترافية أسفل الشاشة تنتهي بـ «تحياتي م / وائل الجمال» |
| **صفحة المولّد (لك وحدك)** | `#/activate` — توليد سيريالات، سجل، إلغاء، إعادة تنشيط، تصدير CSV (رمز دخول تجريبي: `1234`) |
| **التواصل** | صفحة تواصل كاملة + واتساب مباشر 01222355769 مع كود الجهاز مُدرج تلقائياً |

> **كيف تعمل؟** البرنامج لا يحتوي على المفتاح السري ولا يولّد سيريالات — التوليد يحدث فقط في صفحتك `#/activate`. البرنامج يتحقق من السيريال عبر السجل (محاكاة خادم) ثم يعلّمه كمُستهلك. عند النشر الحقيقي اربط السجل بخادم (Supabase/Sheets) عبر `POST /api/verify-license` — الكود المرجعي جاهز في `Services/LicenseService.cs`.

### 📄 أدوات PDF (اقتراح 13)
- إضافة عدة ملفات PDF، ثم **دمج** بترتيب مخصص أو **استخراج** صفحات محددة أو **تقسيم** كل صفحة لملف.
- إعادة ترتيب الصفحات (أعلى/أسفل) + تدوير 90° + حذف صفحات — بمحرك `pdf-lib` حقيقي.

### 🖼️ ضغط الصور لتوفير الحبر (اقتراح 14)
- سحب عدة صور → ضغط على الجهاز (Canvas) مع تحكم في أقصى بعد والجودة.
- توفير فعلي بالبايت + **تقدير نسبة توفير الحبر** + تنزيل الصور المضغوطة.

### 🔍 مقارنة A/B للمستندات (اقتراح 12)

- إحصاءات (تطابق/إضافات/محذوف) + تصدير تقرير TXT + نسخ.
